# Sales Dashboard – Power BI

## Project Overview

This project presents a simple sales dashboard developed using Microsoft Power BI.

## Dashboard Requirements

- Total Revenue
- Sales by Region
- Top 5 Products by Profit

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Excel

## Dashboard Preview

The dashboard provides a visual overview of revenue, regional sales performance, and the top 5 products based on profit.

## Key Features

- Total Revenue KPI
- Regional Sales Analysis
- Top 5 Products by Profit
